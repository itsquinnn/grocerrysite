# DOVAN (दोभान)

Modern premium e-commerce platform curated for Nepal, featuring English and Nepali language support, Cash on Delivery across all 77 districts, eSewa, Khalti, and Fonepay integration, order tracking, and dynamic product catalogs.

## Features
- **Bilingual Experience:** Instant switching between English and Nepali (`EN` ↔ `नेपाली`).
- **All 77 Districts Delivery:** District-based shipping calculators and courier tracking.
- **Local & Digital Payments:** Cash on Delivery (COD), eSewa, Khalti, and Fonepay.
- **Product Discovery:** Full category and subcategory filtering, side-by-side product comparison, wishlist, and search.
- **Customer Account & Invoices:** Order status history, downloadable PDF tax invoices, saved addresses, and customer support ticketing.

## Tech Stack
- **Framework:** TanStack Start / Vite / React 19
- **State & Data Fetching:** TanStack Query
- **Styling:** Tailwind CSS
- **Database & Auth:** Supabase PostgreSQL

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

The application will be running locally at `http://localhost:8080`.
