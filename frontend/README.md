# DOVAN — E-Commerce Platform for Nepal

A modern, high-performance multi-category e-commerce web application featuring nationwide delivery across all 77 districts of Nepal, Cash on Delivery (COD), order tracking, real-time reviews, and account management.

## Development

```sh
npm install
npm run dev
```

## Production Build

```sh
npm run build
npm run preview
```

## Tech Stack

- TanStack Start (SSR) & TanStack Router
- TypeScript & React
- Tailwind CSS v4
- Supabase (PostgreSQL, Auth, Storage)
